# Changelog

All notable changes to PumboFilter, one section per release. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.3-beta] - 2026-10-30

### Added

- Own file for Pumpkin 0.2.0: `PumboFilter-Pumpkin-0.2.0-0.1.3-beta.wasm`.

### Changed

- The 26.3 file is built for Pumpkin 0.2.1 and no longer loads on 0.2.0.
- Faster first start after a crash.
- The database cache takes up to 16 MiB instead of 1 GiB.
- On Pumpkin, config and language files you never edited follow plugin updates.

## [0.1.2-beta] - 2026-10-09

No changes in PumboFilter; released with PumboPerms 0.1.2-beta.

## [0.1.1-beta] - 2026-10-09

### Fixed

- Help pages: the page number works again (`/pf help 2`, the ▶ arrow).

## [0.1.0-beta.1] - 2026-10-09

First public beta.
